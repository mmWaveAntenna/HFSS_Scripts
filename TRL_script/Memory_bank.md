# Memory Bank — TRL + кольцевой резонатор на FR4 для HFSS 2025

## Состояние проекта
- Версия: 2.5.4
- Готово:
  - `hfss_trl_kit.py` — единый скрипт-генератор проекта `TRL_Calibration_FR4_Param` / `TRL_Kit`:
    - 3 TRL-стандарта (THRU, LINE, OPEN_A, OPEN_B) с зависимыми длинами;
    - кольцевой резонатор с TAB из кольца-заготовки;
    - физическая модель коаксиальных разъёмов (G14SFB001, 1.85 мм) с PEC-крышками и Z-смещением пина на 8 мкм;
    - локальные земляные площадки (`TopPad`, 5.58 мм) с технологическим зазором `gap_foil` = 0.2 мм;
    - овальные монтажные пазы (2.0 × 1.4 мм, вдоль оси Y);
    - 8 Wave Ports на диэлектрике (строго симметрично);
    - взаимное вычитание сигнальных и земляных объектов (устранение пересечений).
  - `DEV_LOG.md` — DL-01 … DL-43 + приложение.
- В работе: финальная проверка успешного прогона v2.5.4.
- Не начато:
  - Автоэкспорт `.s2p` после Analyze.
  - Optimetrics-свип при фиксированном `L_thru`.
  - Дисперсионная модель FR4 (Wideband Debye).

## Ключевые решения
- **Параметризация (DL-41, DL-42):** 
  - **HFSS-выражения** для всей геометрии: `L_line`, `r_mean`, `r_out`, `r_in`, `r_tab_in`, `r_tab_out`, `y_top_res`, `x_thru`, `x_line`, `x_open`, `x_res`, `x_left`, `x_right`, `sub_w`, `y_top`, `sub_l`.
  - **Python-числа** только там, где API требует `float` (например, `integration_line` у Wave Port, координата `z_coax`).
- **TRL-длины (DL-17):** `L_ref = L_feed = L_thru/2`, `L_line = L_thru + dL`.
- **Модель разъёма G14SFB001 (DL-19, DL-30):**
  - Коаксиал: `r_pin_coax` = 0.115 мм, `r_diel` = 0.375 мм, `r_outer` = 0.925 мм, длина `L_coax = 150/f0_GHz`.
  - **Z-смещение:** `z_coax = h + t_cu - 0.008mm + r_pin_coax`.
  - **Стенка:** ширина 12.7 мм, высота 9.53 мм, направлена наружу.
  - **Лапки:** ширина 3.175 мм, высота 2.5 мм, покрывают `TopPad`.
- **PEC-крышки (DL-40):** ручные цилиндры `pec`, из которых вычитается диэлектрик (формируется кольцо, порт не перекрыт).
- **Граничные условия:** явные `assign_perfecte_to_sheets` убраны. HFSS назначает Perfect E неявно (Implicit Boundaries) для 3D-объектов из меди (с `Solve Inside = False`).
- **Взаимное вычитание (v2.4.0):** `subtract(sig_name, gnd_name)` и наоборот — устраняет любые случайные пересечения металлов.
- **Пазы (DL-31, DL-33):** формируются объединением двух цилиндров (Ø 2.0 мм) и бокса (2.0 × 1.4 мм). Ориентированы вдоль Y.
- **TopPad (DL-32, DL-36):** длина 5.58 мм, локальные площадки вместо сплошной заливки. Форма пада прямоугольная.

## Совместимость (PyAEDT 1.8.0 / 1.10 / AEDT 2025.1)
- `Hfss(project=, design=, new_desktop=)`
- Примитивы: `origin`, `sizes`; `create_cylinder`: `origin`, `radius`, `height`.
- `hfss.get_evaluated_value(name)` — единственный рабочий способ чтения вычисленных значений.
- `integration_line` — только числа (`float`).
- `unite`, `intersect`, `subtract` — in-place на первом аргументе.
- Запуск PyAEDT: `Automation → Run PyAEDT Script` или внешний CPython.

## Известные ограничения
- **`integration_line`** — числа. При изменении `pitch_trl`, `pitch_res`, `L_thru`, `L_line` или `y_top_res` в `Design Properties` порты **не сдвинутся** автоматически (перезапуск скрипта обязателен).
- **`deembed`** — число. При изменении `L_thru` перезапуск обязателен.
- **3D STEP-модель G14SFB001** отсутствует, размеры взяты из PDF.
- **FR4 без дисперсии.** Для $f > 5$ ГГц — Wideband Debye.
- **Кольцо — $n=1$.** Для других мод — пересчитать `r_mean`.
